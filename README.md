## 🚑 Medical AI Assistant — Micro Project

A simple Next.js + Tailwind micro-app that simulates an AI medical assistant.
Users can type medical questions and receive a generated placeholder response.
Built to demonstrate clean UI, state management, and API handling.

## 🛠️ Tech Used

### Next.js

### React

### Tailwind CSS

### Zustand

### React Query

## 🚀 Run Locally

### Install dependencies:

```bash
npm install
```

Start development server:


```bash
npm run dev
```


### Visit:

```bash
http://localhost:3000
```
